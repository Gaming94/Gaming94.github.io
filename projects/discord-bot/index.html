PROJECT 03 / DISCORD AUTOMATION

운영 일시 중단2026.07 제작

숙제도우미_
컴건봇

여러 캐릭터의 주간 숙제 현황을
Discord 안에서 한눈에 관리하는 자동화 봇

반복되는 게임 콘텐츠를 놓치지 않도록, 캐릭터별 숙제 현황을 기록하고 Discord의 명령어·드롭다운·버튼으로 확인과 체크를 할 수 있도록 제작했습니다.

01 / PROBLEM & GOAL

숙제 관리를
조금 더 간단하게.

다중 캐릭터를 육성하는 게임에서는 캐릭터마다 완료해야 하는 반복 콘텐츠가 쌓입니다. 무엇을 끝냈는지 기억하거나 별도 메모를 확인하는 대신, 게임 이용자들이 모여 있는 Discord 안에서 관리할 방법을 고민했습니다.

단순한 목록 출력이 아니라 캐릭터 전환 → 숙제 체크 → 진행률 확인으로 이어지는 사용 흐름을 구성했습니다.

02 / FEATURES

주요 기능

첨부된 봇 소스코드에서 확인되는 기능을 기준으로 정리했습니다.

06 FEATURES
01

개인 숙제판

/내숙제로 선택한 캐릭터의 주간 숙제와 카테고리별 완료 수를 확인하고, 드롭다운에서 완료·미완료 상태를 전환합니다.

02

다중 캐릭터 관리

유저별로 최대 25개 캐릭터를 등록할 수 있습니다. 추가·이름 변경·삭제와 현재 캐릭터 전환을 지원합니다.

03

계정 공통 항목 연동

[계정]으로 표시된 숙제는 한 캐릭터에서 체크하면 같은 유저의 다른 캐릭터에도 동일한 완료 상태가 적용됩니다.

04

다른 멤버 조회

/숙제조회로 다른 멤버의 캐릭터별 숙제를 열람합니다. 조회 화면에서는 타인의 체크 상태를 수정할 수 없습니다.

05

미완료 숙제 점검

/숙제점검으로 자신이 등록한 모든 캐릭터의 남은 주간 숙제를 모아 확인할 수 있습니다.

06

주간 자동 초기화

한국 시간 기준 월요일 오전 6시에 주간 체크 상태를 초기화합니다. 봇이 실행 중인 동안 주기적으로 시간을 확인하는 방식입니다.

03 / SCREENSHOTS

실제 사용 화면

화면을 선택하면 원본 크기로 확인할 수 있습니다.

05 IMAGES

※ 스크린샷은 운영 당시의 화면입니다. 제공된 소스코드와 일부 숙제 카테고리 구성이 다를 수 있습니다. 이미지 속 개인·서버 정보는 공개 전에 확인이 필요합니다.

04 / DESIGN & IMPLEMENTATION

사용 흐름부터
저장 구조까지.

Python과 discord.py를 사용해 Slash Command, Embed, Select Menu, Button, Modal을 연결했습니다. 각 사용자의 캐릭터별 체크 상태는 JSON 형식으로 관리합니다.

원본 소스코드는 공개하지 않고 실제로 구현한 기능과 구조만 소개합니다.

CHECK FLOW
명령어·메뉴 선택→요청자 및 항목 확인→상태 변경·JSON 저장→Embed 화면 갱신

사용자·캐릭터별 상태 분리

Discord 사용자 ID 기준으로 캐릭터 목록과 활성 캐릭터를 관리하고, 유저 간 체크 상태가 섞이지 않도록 분리했습니다.

기존 데이터 형식 호환

이전 형태로 저장된 데이터를 현재의 캐릭터별 구조로 정규화하는 처리 로직을 두었습니다.

파일 교체 방식의 저장

임시 JSON 파일을 먼저 작성한 다음 원본 파일을 교체하는 방식으로 저장 중 파일 손상 가능성을 줄이도록 설계했습니다.

상호작용 권한 확인

캐릭터 변경·숙제 체크 등 주요 동작은 요청자가 해당 데이터를 관리할 권한이 있는지 확인한 후 처리합니다.

05 / OPERATING NOTES

운영 경험과
개선할 부분.

Discloud에서 봇을 호스팅한 경험이 있으며 현재 서비스는 일시 중단된 상태입니다. 따라서 실시간 사용을 전제로 한 초대 버튼은 제공하지 않습니다.

현재 주간 초기화는 봇이 실행 중인 시각을 기준으로 하므로, 초기화 시점에 서버가 꺼져 있으면 해당 회차를 놓칠 수 있습니다. 이후에는 마지막 초기화 날짜를 저장하고 재시작 시 보정하는 방식으로 개선할 수 있습니다.
